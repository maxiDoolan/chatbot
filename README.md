# 🤖 Chatbot con IA

Chatbot conversacional con memoria, construido con Python, Streamlit y Groq AI.

## 🚀 Demo en vivo
[Probalo acá](https://chatbot-koemd8dqx5mtsmevyrwmu3.streamlit.app/)

## ✨ Features
- Responde en español argentino
- Tiene memoria de la conversación
- Botón para limpiar el chat
- API key protegida con variables de entorno

## 🛠️ Tecnologías
- Python
- Streamlit
- Groq API
- python-dotenv

## ▶️ Correrlo localmente
1. Clonar el repo
2. Instalar dependencias: `pip install -r requirements.txt`
3. Crear `.env` con tu `GROQ_API_KEY`
4. Correr: `python -m streamlit run 20-streamlit-chat.py`
